Importeren uit MS Project

Kies een .mpp-bestand, of een MS Project XML-export (in MS Project: Bestand > Opslaan als > Bestandstype "XML"). Taken dieper dan WBS-niveau 3 worden niet getoond; resources en voorgangers/afhankelijkheden worden niet overgenomen — Doelenboom kent daar geen velden voor. Bij een herimport wordt het bestand vergeleken met eerder geïmporteerde activiteiten: nieuwe taken worden toegevoegd (nieuw), gewijzigde taken bijgewerkt (wijzigen) en taken die niet meer in het plan voorkomen aangeboden om te verwijderen (verwijderen) — controleer de lijst dus goed voordat u bevestigt. Handmatig aangemaakte activiteiten worden nooit door een import aangeraakt.

Project-gegevens: Excel

Exporteer alle gegevens van dit project (producten, activiteiten, projectstatus, tags en organisatieonderdelen) als Excel-bestand, of importeer een eerder geëxporteerd (en eventueel bewerkt) bestand terug. Een import toont eerst een wijzigingsoverzicht — er wordt niets toegepast vóór bevestiging. Producten/activiteiten worden gematcht op hun ID-kolom: een lege ID wordt een nieuw item, en een bestaand item waarvan de ID niet meer in het bestand voorkomt wordt aangeboden om te verwijderen.
